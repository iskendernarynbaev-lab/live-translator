# 🎧 Локальный переводчик звонков (англ → рус)

Реалтайм-субтитры на русском для звонков в **Zoom** (или любом приложении, где есть звук).
Всё считается **локально на твоём Mac** — звук никуда не отправляется в интернет, платить не нужно.

Удобно, когда собеседник говорит по-английски, а хочется не терять нить и держать контекст.

```
        речь собеседника
              │
        BlackHole (виртуальный звук)
              │
   ┌──────────┴───────────┐
   │  распознавание (Whisper)  →  «живой» английский сверху
   │  перевод (qwen3 / argos)  →  русский снизу
   └──────────┬───────────┘
              │
      окно с субтитрами поверх Zoom
```

Как это ощущается: пока человек говорит, сверху мелким шрифтом набирается английский,
а снизу крупно появляется русский перевод — по словам, не дожидаясь конца фразы.

---

## Что внутри

- **Распознавание речи** — [faster-whisper](https://github.com/SYSTRAN/faster-whisper), офлайн, модель `small.en` (англ.).
- **Перевод** — локальный LLM **qwen3** через [Ollama](https://ollama.com) (естественный, с учётом контекста).
  Если Ollama не запущена — автоматически откатывается на офлайн-движок **argos**.
- **Нарезка речи** — VAD + «скользящее окно», чтобы субтитры шли потоком, а не после каждой паузы.
- **Приватность** — весь звук и текст остаются на твоём компьютере.

Задержка на Apple Silicon: **~1–1.5 сек**. Английский появляется почти мгновенно,
русский догоняет стримингом.

---

## Требования

- **Mac на Apple Silicon** (M1/M2/M3/M4) — на нём всё быстро. На Intel тоже пойдёт, но медленнее.
- **[Homebrew](https://brew.sh)** — менеджер пакетов для macOS.
- **Python 3.10+**.
- **(Опционально, но рекомендуется)** [Ollama](https://ollama.com) с моделью `qwen3` — для качественного перевода.
  Без неё перевод работает через argos (проще, но грубее).

## Установка

### 1. Системные зависимости

```bash
# аудиодрайвер (перехват звонка), звуковая библиотека и Tk для окна субтитров
brew install blackhole-2ch portaudio python-tk
```

### 2. Python-зависимости

```bash
pip install -r requirements.txt
```

> При первом запуске argos разово скачает офлайн-пакет перевода (тянет PyTorch, ~пара ГБ).
> Если пользуешься только Ollama — argos подгрузится лишь как резерв.

### 3. Ollama для качественного перевода (рекомендуется)

```bash
# установить Ollama: https://ollama.com/download  (или: brew install ollama)
ollama pull qwen3:14b        # мощная модель (нужно ~10 ГБ и приличный Mac)
# или полегче и быстрее:
ollama pull qwen2.5:7b
```

Перед запуском убедись, что сервер поднят (обычно стартует сам; если нет — `ollama serve`).

## Настройка звука (один раз)

Чтобы приложение слышало собеседника, а **ты продолжал слышать его в наушниках**,
нужно составное устройство вывода:

1. Открой **Audio MIDI Setup** (Настройка Audio-MIDI) — через Spotlight (Cmd+Space).
2. Внизу слева **«+»** → **Create Multi-Output Device**.
3. Поставь галочки на **свои наушники/динамики** и на **BlackHole 2ch**.
4. Назови его, например, `Zoom + Перевод`.
5. В **Системные настройки → Звук → Выход** выбери это составное устройство.

Теперь звук идёт одновременно тебе в уши и в приложение. Переводится речь **собеседника**
(то, что играет из динамика); твой микрофон не трогаем.

## Запуск

```bash
python realtime_translator.py
```

Появится чёрное окно внизу экрана (его можно перетаскивать мышью). Включи любое
англоязычное видео на YouTube для проверки — субтитры должны пойти.

### Флаги

| Флаг | Что делает |
|------|-----------|
| `--ollama-model qwen2.5:7b` | другая модель Ollama (полегче/быстрее) |
| `--argos` | переводить офлайн-движком argos вместо Ollama |
| `--model medium.en` | точнее распознавание (чуть выше задержка) |
| `--model base.en` | быстрее распознавание (чуть ниже качество) |
| `--no-original` | показывать только перевод, без английского |
| `--console` | вывод в терминал вместо окна |
| `--list-devices` | показать аудиоустройства и выйти |

Примеры:

```bash
python realtime_translator.py --ollama-model qwen2.5:7b   # быстрее перевод
python realtime_translator.py --model medium.en           # точнее распознавание
python realtime_translator.py --argos --console           # офлайн, в терминал
```

## Тонкая настройка (задержка vs качество)

В начале `realtime_translator.py` есть параметры:

- `FINALIZE_SILENCE_MS` (450) — сколько тишины считать концом куска.
  Меньше → быстрее субтитры, но чаще рвёт фразы.
- `MAX_CHUNK_MS` (4500) — принудительная фиксация в непрерывной речи, чтобы не ждать паузы.
- `REFRESH_MS` (700) — как часто обновляется «живой» английский.
- `--model` — `base.en` / `small.en` / `medium.en` — скорость ↔ качество распознавания.
- `--ollama-model` — крупнее модель → лучше перевод, но выше задержка.

## Если что-то не так

- **`No module named 'pkg_resources'`** → `pip install setuptools`
  (или замени `webrtcvad` на `webrtcvad-wheels`).
- **Окно не открывается / `_tkinter`** → `brew install python-tk` (под свою версию Python).
  Как запасной вариант — запусти с `--console`.
- **«Не нашёл устройство BlackHole»** → проверь `brew install blackhole-2ch`,
  перезапусти аудиослужбу `sudo killall coreaudiod`, глянь `--list-devices`.
  Если драйвер не появляется — перезагрузи Mac один раз.
- **Нет звука после настройки** → в выводе выбран сам «BlackHole 2ch», а надо
  **Multi-Output Device** (где галки и на наушниках, и на BlackHole).
- **Русский заметно отстаёт** → возьми модель полегче:
  `ollama pull qwen2.5:7b` и `--ollama-model qwen2.5:7b`.
- **`Ollama не отвечает`** → запусти `ollama serve`, либо работай через `--argos`.

## Приватность

Ничего не уходит в облако: распознавание, перевод и звук обрабатываются локально.
Ollama и Whisper работают офлайн, argos — тоже. Для звонков это важно.
